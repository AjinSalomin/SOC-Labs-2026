# Detecting Web Attacks

## Overview
I completed the Detecting Web Attacks training on LetsDefend as part of my journey toward becoming a SOC Analyst.

This hands-on learning experience helped me understand how web-based attacks occur, how suspicious web traffic can be identified, and how security analysts investigate potential threats using available security logs and indicators.

## Objectives
The main objectives of this training were to:

* Understand common web-based attacks.
* Identify suspicious HTTP requests and unusual web traffic.
* Recognize potential attack patterns in web server logs.
* Understand how attackers exploit web application vulnerabilities.
* Improve web attack detection and investigation skills.
* Develop a better understanding of the SOC analyst investigation process.

## Key Learnings
During this training, I strengthened my understanding of:

* Common web attack techniques.
* Suspicious HTTP requests and response patterns.
* Identifying potentially malicious web traffic.
* Analyzing web attack indicators.
* Understanding attacker behavior and techniques.
* The importance of monitoring and investigating web traffic.

## Skills Developed
* Web Attack Detection
* Log Analysis
* HTTP Traffic Analysis
* Threat Identification
* Security Event Investigation
* SOC Analysis Fundamentals

## Practical Experience
This training helped me improve my ability to recognize suspicious web activity and understand how web attacks can appear during security monitoring.

It also strengthened my understanding of how SOC analysts investigate potential web-based threats and why continuous monitoring is important for identifying malicious activity.
