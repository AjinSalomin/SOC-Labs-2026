# Investigate Web Attack 

## Overview

Completed the Investigate Web Attack practical investigation on LetsDefend to develop my SOC Analyst skills in identifying, analysing, and investigating suspicious web attack activity.

This lab helped me understand how to investigate potential web-based threats and analyse security events from a Blue Team perspective.

## Objectives

* Understand common web attack activities.
* Investigate suspicious HTTP requests.
* Analyse security alerts and related log information.
* Identify potentially malicious activity.
* Understand the investigation and escalation process.

## Skills Practiced

* SOC Alert Investigation
* Web Attack Analysis
* Log Analysis
* Security Event Investigation
* Threat Detection
* Incident Documentation
* Blue Team Fundamentals

## Tools & Platform

* Platform: LetsDefend
* Focus Area: SOC Operations
* Domain: Web Application Security

## Key Learnings

* Improved my understanding of web-based attack investigations.
* Practiced analysing security alerts and suspicious activity.
* Developed a structured approach to security event investigation.
* Understood the importance of documenting findings before escalating incidents.

## Learning Outcome

This practical exercise strengthened my foundational SOC Analyst investigation skills and improved my understanding of web attack analysis.
